# Documentation

This repository contains documentation and guides for our customers.

## Playbooks

Documentation for the `ansible-playbooks-*` repositories that contain the Ansible playbooks for your servers.

[playbooks/AGENTS.md](playbooks/AGENTS.md) - Instructions for AI agents that make changes to the playbooks.  
[playbooks/conventions.md](playbooks/conventions.md) - An overview of our playbook conventions.  
[playbooks/github.md](playbooks/github.md) - A basic GitHub guide on how to create a pull request with playbook changes.  
[playbooks/roles](playbooks/roles) - The readmes for our most commonly used Ansible roles with the available variables.  
[playbooks/vars](playbooks/vars) - Example vars files for our most commonly used Ansible roles.
